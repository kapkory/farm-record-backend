# Farm Management System - Documentation

A comprehensive farm management system backend built with Laravel 12, designed to help small-scale and large-scale farmers manage their agricultural operations as a business.

## Quick Links

- **API Base URL:** `http://localhost:8000/api/v1`
- **Frontend:** Nuxt.js (http://localhost:3000)
- **Authentication:** Laravel Sanctum (SPA cookie-based)

## Tech Stack

| Component | Technology |
|-----------|------------|
| Framework | Laravel 12 |
| PHP Version | 8.2+ |
| Authentication | Laravel Sanctum |
| Database | MySQL |
| Testing | Pest PHP |
| Frontend | Nuxt.js |

## Current Modules

- ✅ User Authentication (Login, Register, Password Reset)
- ✅ Farmer Management (Individual, Group, Organization)
- ✅ Farm Management (CRUD operations)
- ✅ Crop Types & Varieties
- 🔲 Fields Management
- 🔲 Livestock Management
- 🔲 Planting & Harvest Tracking
- 🔲 Financial Tracking (Expenses/Revenue)
- 🔲 Reports & Analytics
